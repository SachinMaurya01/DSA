<------------------------------ BackTracking --------------------------->

Backtracking:-  Backtracking is a problem-solving algorithmic technique that involve
            finding a solution incrementally by trying different options and undoing
            them if they lead to a dead end.
    
    Example:- like searching for a path in a maze or solving puzzles like Sudoku.

    => The following is a general outline of how a backtracking algorithm works:
        1. Choose an initial solution.
        2. Explore all possible extensions of the current solution.
        3. If an extension leads to a solution, return that solution.
        4. If an extension does not lead to a solution, backtrack to the previous
            solution and try a different extension.
        5. Repeat steps 2-4 until all possible solutions have been explored.

Q -> When to Use a Backtracking Algorithm?
-> Backtracking algorithms are best used to solve problems that have the following characteristics:
    1. There are multiple possible solutions to the problem.
    2. The problem can be broken down into smaller subproblems.
    3. The subproblems can be solved independently.

    =>  Applications of Backtracking Algorithm
        Backtracking algorithms are used in a wide variety of applications, including:

        1. Solving puzzles (e.g., Sudoku, crossword puzzles)
        2. Finding the shortest path through a maze
        3. Scheduling problems
        4. Resource allocation problems
        5. Network optimization problems
        6. Combinatorial problems, such as generating permutations, combinations, or subsets.


Example:-  N-Queens Problems
    class Solution {
    public:
        void solve(int col, vector < string > & board, vector <vector<string>> & ans, vector<int>
          & leftrow, vector < int > & upperDiagonal, vector < int > & lowerDiagonal, int n) {
            if (col == n) {
                ans.push_back(board);
                return;
            }
            for (int row = 0; row < n; row++) {
                if (leftrow[row] == 0 && lowerDiagonal[row + col] == 0 && 
                  upperDiagonal[ ( n - 1 ) +  (row - col) ] == 0) {
                    board[row][col] = 'Q';
                    leftrow[row] = 1;
                    lowerDiagonal[row + col] = 1;
                    upperDiagonal[ ( n - 1 ) +  (row - col) ] = 1;
                    solve(col + 1, board, ans, leftrow, upperDiagonal, lowerDiagonal, n);
                    // backtrack mark all value to its previous state
                    board[row][col] = '.';
                    leftrow[row] = 0;
                    lowerDiagonal[row + col] = 0;
                    upperDiagonal[ ( n - 1 ) +  (row - col) ] = 0;
                }
            }
        }

    public:
        vector < vector < string >> solveNQueens(int n) {
        vector < vector < string >> ans;
        vector < string > board(n);
        string s(n, '.');
        for (int i = 0; i < n; i++) {
            board[i] = s;
        }
        vector < int > leftrow(n, 0), upperDiagonal(2 * n - 1, 0), lowerDiagonal(2 * n - 1, 0);
        solve(0, board, ans, leftrow, upperDiagonal, lowerDiagonal, n);
        return ans;
        }
    };

    Time Complexity: Exponential in nature since we are trying out all ways, to be precise it is O(N! * N).
    Space Complexity: O(N)

    NOTE:- For checking upper diagonal , we can (row - col) but its value will be negative and we can't create
            negative size array. So, we can add ( n - 1 )  -> [ ( n - 1 ) +  (row - col) ] in it to avoid negative index.
