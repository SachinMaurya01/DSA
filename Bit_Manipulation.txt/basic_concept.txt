<--------------------------------------     Bitwise Operators    ----------------------------------------------->

1. The & (bitwise AND) ->  in C takes two numbers as operands and does AND on every bit of two numbers.
     The result of AND is 1 only if both bits are 1.  
    Example:- 5 & 3 => 0101 & 0011 = 0001 (1)

2. The | (bitwise OR) -> in C takes two numbers as operands and does OR on every bit of two numbers.
     The result of OR is 1 if any of the two bits is 1. 
    Example:- 5 | 3 => 0101 & 0011 = 0111 (12)


3. The ^ (bitwise XOR) -> in C takes two numbers as operands and does XOR on every bit of two numbers.
     The result of XOR is 1 if the two bits are different. 
    Example:- 5 ^ 3 => 0101 ^ 0011 = 0110 (6)


4. The << (left shift) -> in C takes two numbers, the left shifts the bits of the first operand, and
     the second operand decides the number of places to shift. 
    Example:- 5 << 1 => 0101 << 1 = 1010 (10)


5. The >> (right shift) -> in C takes two numbers, right shifts the bits of the first operand, and the
     second operand decides the number of places to shift. 
    Example:- 5 >> 1 => 0101 >> 1 = 0010 (2)


6. The ~ (bitwise NOT) -> in C takes one number and inverts all bits of it
    Example:- ~5 => ~0101 = ...11111010 (-6)



// Notes:-
    1. The left-shift and right-shift operators should not be used for negative numbers.
        Example:- If the second operand(which decides the number of shifts) is a negative number, it results
            in undefined behavior in C. For example, results of both 1 <<- 1 and 1 >> -1 are undefined.
    
    2. The bitwise XOR operator is the most useful operator from a technical interview perspective.

    3. The Bitwise operators should not be used in place of logical operators.The result of logical operators
        (&&, || and !) is either 0 or 1, but bitwise operators return an integer value. Also, the logical
        operators consider any non-zero operand as 1.
    
    4. The left-shift and right-shift operators are equivalent to multiplication and division by 2 respectively.

    5. The ~ operator should be used carefully. The result of the ~ operator on a small number can be a big
        number if the result is stored in an unsigned variable.
