Question 1. Find intersection of Two Linked Lists

Problem Statement: Given the heads of two singly linked-lists headA and headB, return the
    node at which the two lists intersect. If the two linked lists have no intersection at all, return null.

Example 1:
    Input: List 1 = [1,3,1,2,4], List 2 = [3,2,4]
    Output: 2

// Intitution / Approach :-

1. We can use hashing to store one node nodes. Then iterate second one and check if in map it is present. 

2. We can get both length and skip initial node for bigger length. Then iterate and find the common node.

3. Most optimised approach, If we can take 2 dummy pointer with two nodes and start iterate if first one 
    is null and point it to another head. If will create infinite loop. In one case , we will find the 
    values otherwise it will be NULL.

// CODE LOGIC:-

    // HAshing Solution
    node* intersectionPresent(node* head1,node* head2) {
        unordered_set<node*> st;
        while(head1 != NULL) {
        st.insert(head1);
        head1 = head1->next;
        }
        while(head2 != NULL) {
            if(st.find(head2) != st.end()) return head2;
            head2 = head2->next;
        }
        return NULL;
    }

    // Skip nodes Solution 
    int getDifference(node* head1,node* head2) {
        int len1 = 0,len2 = 0;
        while(head1 != NULL || head2 != NULL) {
            if(head1 != NULL) {
                ++len1; head1 = head1->next;
            }
            if(head2 != NULL) {
                ++len2; head2 = head2->next;
            }  
        }
        //if difference is neg-> length of list2 > length of list1 else vice-versa
        return len1-len2;
    }

    node* intersectionPresent(node* head1,node* head2) {
        int diff = getDifference(head1,head2);
        if(diff < 0) 
            while(diff++ != 0) head2 = head2->next; 
        else while(diff-- != 0) head1 = head1->next;
        while(head1 != NULL) {
            if(head1 == head2) return head1;
            head2 = head2->next;
            head1 = head1->next;
        }
        return head1;
    } 

    // Loop Solution
    node* intersectionPresent(node* head1,node* head2) {
        node* d1 = head1;
        node* d2 = head2;
        
        while(d1 != d2) {
            d1 = d1 == NULL? head2:d1->next;
            d2 = d2 == NULL? head1:d2->next;
        }
        
        return d1;
    }

Question 2: Reverse Linked List in groups of Size K

Problem Statement: Given the head of a singly linked list of `n` nodes and an integer `k`,
    where k is less than or equal to `n`. Your task is to reverse the order of each group 
    of `k` consecutive nodes, if `n` is not divisible by `k`, then the last group of remaining
    nodes should remain unchanged.

LINK:- https://leetcode.com/problems/reverse-nodes-in-k-group/

// Intitution / Approach :-

1. We can use recursion to ierate all nodes. For every k , we reversed the nodes. Then call
    recursion for other nodes.
2. To prevent last less than k nodes. We loop till k in recursion. If nodes is left Before
    reaching kth position . We will return head;

// CODE LOGIC:-
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode* cursor= head;
        // To prevent last nodes reverse
        for(int i=0;i<k;i++){
            if(cursor == NULL) return head;
            cursor=cursor->next;
        }
        ListNode* prev=NULL;
        ListNode* cur=head;
        ListNode* nxt=NULL;
        // Reverse kth nodes
        for(int i=0;i<k;i++){
            nxt = cur->next;
            cur->next = prev;
            prev=cur;
            cur=nxt;
        }
        head->next = reverseKGroup(cur,k);
        return prev;

    }
