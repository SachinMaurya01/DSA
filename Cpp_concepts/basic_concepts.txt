
// Data Types:- 

    -> Basic Data Types:-
    	Built-in or primitive data types that are used to store simple values.
        
        Ex:-    
            int ( 4 bytes ) -> ( -2147483648 to +2147483647 ) -> ( —10^9 to +10^9 ) 
            long int ( 4 or 8 bytes ) -> ( -9223372036854775808 to +9223372036854775807 )
            long long int ( 8 bytes )  -> ( -9223372036854775808 to +9223372036854775807 ) -> ( 2^63 – 1 )
            float ( 4 bytes )  -> ( 1.17549e-38 to 3.40282e+38 )
            double float ( 8 bytes )  ->  ( 2.22507e-308 to 1.79769e+308 )
            long double (  16 or more bytes)  ->  ( -2.22507e-308 to -1.79769e+308 )
            char ( 1 bytes )  -> ( -128 to 127 )
            bool ( 1 bytes ) 
            void ( its no type function )


    -> Derived Data Types:-
    	Data types derived from basic types.
        Ex:- array, pointer, reference, function

    -> User Defined Data Types:-
    	Custom data types created by the programmer according to their need.
        Ex:- class, struct, union, typedef, using



// Header files
    Header files in C++ contain declarations of functions, classes, and variables that can be
    used in multiple source files. They typically have a .h or .hpp extension.

    => Types of Header Files:-

        1. Standard Library Headers (Built-in) -
            -  Provided by C++ standard libraries.
            -  Included using angle brackets (< >).
            -  Example: #include <iostream>


        2. User-Defined Headers (Custom)
            -  Created by the programmer.
            -  Included using double quotes (" ").
            -  Example: #include "myheader.h"

    Note:-  
        1.  #include <bits/stdc++.h> 
                -  we can use this generic header file which include all header files
                -  It is not part of the official C++ standard
                -  It works in GCC/G++ compilers 

                Cons:- 
                    -  Slower compilation time
                    -  Non-portable ( It only works on GCC; other compilers (like MSVC) 
                        may not support it. )
                    -  Not recommended for large projects

        2.  using namespace std; 
                -  This allows direct access to symbols in the std namespace without 
                    prefixing them with std::
                -  The std namespace contains all C++ Standard Library functions and 
                    classes (like cout, vector, string, etc.)

                Cons:- 
                    -  Can cause name conflicts

            Alternative:-  
                // It will work same
                using std::cout;
                using std::endl;


// Tuples
    In C++, a tuple is a data structure that allows you to store multiple values of different types
    together. It is similar to an array or a struct, but with a more flexible and dynamic nature.

    // Note:-
        * This file specifically covers the topic of tuples in C++.
        * Tuples are a way to store multiple elements of different types in a single object.
        * They are similar to pairs, but can hold more than two elements.

    Example:- queue<tuple<TreeNode*,int,int>>q;


// Multiset :- 
    1. Multiset is an associative container similar to the set, but it can store multiple elements with
        same value.
    2. It is sorted in increasing order by default

    Example:-  multiset<int> ms = {5, 1, 3, 3};
