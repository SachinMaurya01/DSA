
// Data Types:- 

    -> Basic Data Types:-
    	Built-in or primitive data types that are used to store simple values.

        Ex:-    
            int ( 4 bytes ) -> ( -2147483648 to +2147483647 ) -> ( —10^9 to +10^9 ) 
            long int ( 4 or 8 bytes ) -> ( -9223372036854775808 to +9223372036854775807 ) -> ( -10^18 to –10^18 )
            long long int ( 8 bytes )  -> ( -9223372036854775808 to +9223372036854775807 ) -> ( 2^63 – 1 )
            float ( 4 bytes )  -> ( 1.17549e-38 to 3.40282e+38 )
            double float ( 8 bytes )  ->  ( 2.22507e-308 to 1.79769e+308 )
            long double (  16 or more bytes)  ->  ( -2.22507e-308 to -1.79769e+308 )
            char ( 1 bytes )  -> ( -128 to 127 )
            bool ( 1 bytes ) 
            void ( its no type function )


    -> Derived Data Types:-
    	Data types derived from basic types.
        Ex:- array, pointer, reference, function

    -> User Defined Data Types:-
    	Custom data types created by the programmer according to their need.
        Ex:- class, struct, union, typedef, using



=> Upper and lower :-

// Header files
    Header files in C++ contain declarations of functions, classes, and variables that can be
    used in multiple source files. They typically have a .h or .hpp extension.

    => Types of Header Files:-

        1. Standard Library Headers (Built-in) -
            -  Provided by C++ standard libraries.
            -  Included using angle brackets (< >).
            -  Example: #include <iostream>


        2. User-Defined Headers (Custom)
            -  Created by the programmer.
            -  Included using double quotes (" ").
            -  Example: #include "myheader.h"

    Note:-  
        1.  #include <bits/stdc++.h> 
                -  we can use this generic header file which include all header files
                -  It is not part of the official C++ standard
                -  It works in GCC/G++ compilers 

                Cons:- 
                    -  Slower compilation time
                    -  Non-portable ( It only works on GCC; other compilers (like MSVC) 
                        may not support it. )
                    -  Not recommended for large projects

        2.  using namespace std; 
                -  This allows direct access to symbols in the std namespace without 
                    prefixing them with std::
                -  The std namespace contains all C++ Standard Library functions and 
                    classes (like cout, vector, string, etc.)

                Cons:- 
                    -  Can cause name conflicts

            Alternative:-  
                // It will work same
                using std::cout;
                using std::endl;


// Tuples
    In C++, a tuple is a data structure that allows you to store multiple values of different types
    together. It is similar to an array or a struct, but with a more flexible and dynamic nature.

    // Note:-
        * This file specifically covers the topic of tuples in C++.

        * They are similar to pairs, but can hold more than two elements.

// Multiset :- 
    1. Multiset is an associative container similar to the set, but it can store multiple elements with
        same value.
    2. It is sorted in increasing order by default

    Example:-  multiset<int> ms = {5, 1, 3, 3};

// Sort pair vector:-

    1. It sorts the vector n1 in ascending order based on the first value of the pairs.
    2. If the first values are equal, it further sorts the pairs based on the second value in ascending order.

    // Code Logic:-
        sort(n1.begin(),n1.end(), [](const pair<int,int>&a, const pair<int,int>&b){
            if(a.first == b.first) return a.second < b.second;
            return a.first < b.first;
        });


// Compare max and min value between variables:-

    => Max :- ( 2 ways )
        1. First way:-
            Ex:-  max(ans,max(v1,v2));
        
        2. Second  way:-
            Ex:- max({ ans, v1, v2 });

    => Min :- ( 2 ways )
        1. First way:-
            Ex:-  min(ans,min(v1,v2));
        
        2. Second  way:-
            Ex:- min({ ans, v1, v2 });


// Some C++ concepts:- 

    1. stringstream :- manipulate strings as if they were input or output streams.
        -> It is particularly useful for parsing, tokenizing, converting data types, and generating formatted strings.

        Example:- 
                1. stringstream ss("Hello 123 World");
                    output-> Hello
                             123
                             World

        => Key Operations with stringstream:-
        
            1. Initialization:-
                Ex:- stringstream ss("Hello 123 World");

            2. Insertion (<<): It inserts data into the stream.
                Ex:- ss << "Data: " << 42 << " " << 3.14;

            3. Extraction (>>): It extracts formatted data.
                Ex:-    string word;
                        int num;
                        ss >> word >> num; // Extracts "Data:" and 42

    
    2. getline() -> Useful when reading multi-word strings with spaces.

            Syntax:- getline(istream& input, string& str, char delimiter = '\n');
            Parameters:
                1. input: Input stream, typically cin or ifstream.
                2. str: String variable to store the input.
                3. delimiter (optional): Character that marks the end of input (default is newline '\n').

            Example:- 
                // Here, getline() will stop reading at the first comma (',').
                    string data;
                    cout << "Enter comma-separated values: ";
                    getline(cin, data, ',');
                    cout << "First value: " << data << endl;


// Implement data structure in C++:-

    => Structures (also called structs) are a way to group several related variables into one place.
        Each variable in the structure is known as a member of the structure.

    Example:- 
        struct Packet {
            int source;
            int destination;
            int timestamp;
            
            Packet(int s, int d, int t) : source(s), destination(d), timestamp(t) {}
            
            bool operator==(const Packet& other) const {
                return source == other.source && 
                    destination == other.destination && 
                    timestamp == other.timestamp;
            }
        };
