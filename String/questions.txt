Question 2. Longest Palindrome in a string

Problem Statement: Given a string s, return the longest palindromic substring in s.

LINK:- https://leetcode.com/problems/longest-palindromic-substring/description/


-> Approach/Intitution
    // Approach 1
        1. We will iterate from 0 to n size. In every iteration , we call expand function to
            check bestleft and bestright .
        2. We call expand func two times with ( i , i ) for odd length palindrome and ( i,i+1 )
            for even length palindrome.
        3. Inside each expand we will keep check s[l] == s[r] and ( l , r ) within boundaries.
            We will keep update (l-- ; r++ ; ) 
        4. At end we will check if r-l+1 > bestRight - bestLeft + 1 , then we will updated answer.
    
    // Approach 2
        1. We are using DP approach . Create a 2D vector with bool value.
        2. We will iterate from a= (0 to n):
                iterate from b =( 0 to a):
                    Check ( a == b ) and ( difference ( a - b >= 2 ) or dp[b+1][a-1] == true ):
                        Then we will mark it true ( dp[j][i] );
                        We will compare it with maxLen and if it is greater then update it 
        


// Code Logic:- 

    void expand(string s,int l,int r,int &bestLeft,int &bestRight){
    while(l>=0 && r<s.size() && s[l]==s[r]){
        l--;
        r++;
    }
    l++;r--;
    if(r-l+1 > bestRight-bestLeft+1){
        bestRight=r;
        bestLeft=l;
    }
}
    string longestPalindrome(string s) {
        int bestLeft=0;
        int bestRight=0;

        // int n=s.size();
        // for(int i=0;i<s.size();i++){
        //     expand(s,i,i,bestLeft,bestRight);
        //     expand(s,i,i+1,bestLeft,bestRight);
        // }

        // return s.substr(bestLeft,bestRight-bestLeft+1);

        int n=s.size();
        int maxLen=1;
        vector<vector<bool>>ans(n,vector<bool>(n,false));
        for(int i=0;i<n;i++){
            ans[i][i]=true;
            for(int j=0;j<i;j++){
                if(s[i]==s[j] && (i-j<=2 || ans[j+1][i-1])){
                    ans[j][i]=true;
                    if(i-j+1 > maxLen){
                        maxLen=i-j+1;
                        bestLeft=j;
                        bestRight=i;
                    }
                }
            }
        }
        return s.substr(bestLeft,bestRight-bestLeft+1);
    }

Q3:- String to Integer (atoi)

Problem Statement: Implement the myAtoi(string s) function, which converts a string to a 32-bit signed integer.

LINK:- https://leetcode.com/problems/string-to-integer-atoi/description/


-> Approach/Intitution
    1. We will initially remove all whitespace and check the sign if it has.
    2. Then we start iterating , if we any character is within the range of (0,9). 
    3. Inside condition, we will add the char into our ans. Atlast we check , if it crossing int min and max limit.
    4. If yes, then we multiply it with sign and return it.


// Code Logic:-

    int myAtoi(string s) {
        int sign = 1;
        long int num = 0;
        int i=0;
        while( i<s.size() && s[i]==' ') i++;
        if(s[i]=='-' || s[i]=='+'){
            sign = s[i] == '-' ? -1 : 1;
            i++;
        }
        while( i<s.size() && (s[i]-'0' >= 0 && s[i]-'0' <= 9)){
            num = num * 10 + (s[i]-'0');
            i++;
            if(num > INT_MAX){
                return sign == -1 ? INT_MIN : INT_MAX;
            }
        }

        return sign * num;
    }

Q4:- Repeated String Match
Problem Statement: Given two strings a and b, return the minimum number of times you should repeat string
    a so that string b is a substring of it.

LINK:- https://leetcode.com/problems/repeated-string-match/description/


-> Approach/Intitution
    // Brute Force:- 
        1. Intially we check the difference of length between source and target. Then we make source same size
            as target or greater than target.
        2. We can directly use Nested for loop to find the string between them.
        3. If we found the match return its difference of length count.

    // Optimise:-
        We are going to use KMP search ( pattern matching algo ) :- 
        Logic will be same till the difference length modification . We change only comparison Logic.
        1. If character matches then increment both i and j.
        2. If not , then check j is greater than find the j whose value will be same as i.
        3. If j==0 then fill it with 0.

// Code Logic:- 

    int KMP_search(string s,string p){
        int m=s.size();
        int n=p.size();

        vector<int>lps(n,0);
        int len=0, i=1;

        while(i<n){
            if(p[len]==p[i]){
                len++;
                lps[i]=len;
                i++;
            }else{
                if(len!=0){
                    len=lps[len-1];
                }else{
                    lps[i]=0;
                    i++;
                }
            }
        }

        i=0;
        int j=0;
        while(i<m && j<n){
            if(s[i]==p[j]){
                i++;
                j++;
                if(j==n){
                    return true;
                }
            }else{
                if(j!=0){
                    j=lps[j-1];
                }else{
                    i++;
                }
            }
        }
        return false;
    }

    int repeatedStringMatch(string a, string b) {
        if(a==b) return 1;

        int count=1;
        string source = a;
        while(source.size() < b.size()){
            source+=a;
            count++;
        }

        if(source==b) return count;
        if(KMP_search(source,b)) return count;
        if(KMP_search(source+a,b)) return count+1;
        return -1;
    }
